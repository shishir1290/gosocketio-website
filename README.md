# gsocketio Website & Documentation Portal

This repository contains the official Next.js website and documentation portal for **[gsocketio](https://github.com/shishir1290/gsocketio)** — the zero-dependency pure-Go Socket.IO v4 server.

## Features

- **Built with Next.js (App Router)** & TypeScript
- **Animations with GSAP & Framer Motion**
- **Interactive Step-by-Step Documentation**: Comprehensive code recipes for authentication, context, rooms, acknowledgments, binary buffers, and configuration.
- **Cross-Platform Code Hub**: Ready-to-use snippets for JS/React/Next.js, Python, Flutter, Swift, Kotlin, and Unity.
- **Wireframe Protocol Visualizer**: Step-by-step trace of Engine.IO v4 / Socket.IO v4 frames.
- **Live Simulator Playground**: Test and inspect simulated real-time WebSocket packets directly in the browser.
- **API Reference**: Searchable interface and method tables for the Go library.

## Getting Started

Install dependencies:
\`\`\`bash
npm install
\`\`\`

Start the development server:
\`\`\`bash
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000) to view the website.

## Production Build

\`\`\`bash
npm run build
npm run start
\`\`\`
